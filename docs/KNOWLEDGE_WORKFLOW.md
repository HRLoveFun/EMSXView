## 双轨制更新策略

### 为什么需要双轨制？

| 维度 | 快速轨道 (Weekly) | 审核轨道 (Monthly) |
|------|-------------------|-------------------|
| **时效性** | 高 (每周更新) | 中 (每月更新) |
| **全面性** | 中 (自动提取) | 高 (人工判断) |
| **人工介入** | 低 (仅查看) | 高 (需确认) |
| **产出位置** | SESSION_DIGEST.md | ERROR_PATTERNS.md + MEMORY.md |
| **目的** | 跟踪趋势、发现模式 | 沉淀知识、建立规范 |

### 工作流程

```
第一周 ──────────────────────────────────────►
  │
  ├── 日常开发 → 记录到 HANDOFF.md
  │
  └── 下周一 09:00
      └── 自动生成 SESSION_DIGEST.md
          ├── 本期摘要
          └── 待办清单 [待审核]
               ├── [ ] 新错误模式 A → ERROR_PATTERNS?
               └── [ ] 架构决策 B → MEMORY?

第二周 ──────────────────────────────────────►
  │
  ├── 日常开发 → 记录到 HANDOFF.md
  │
  ├── 周一 09:00
  │   └── 更新 SESSION_DIGEST.md
  │       ├── 新：本期摘要
  │       └── 保留：上期摘要 → 历史归档
  │
  └── 随时：用户查看待办清单
      └── 确认是否加入正式知识库

月底 ────────────────────────────────────────►
  │
  └── 每月 1 日 10:00
      └── 自动执行 knowledge-review-monthly
          ├── 汇总本月待办清单
          ├── 建议合并相似条目
          ├── 更新统计信息
          └── 生成月度报告

用户审核 ────────────────────────────────────►
  │
  ├── 查看月度报告
  ├── 确认有价值的条目
  │   └── 手动/AI协助更新 ERROR_PATTERNS.md
  ├── 确认架构决策
  │   └── 手动/AI协助更新 MEMORY.md
  └── 清空 SESSION_DIGEST.md 待办清单
```

## 自动化任务配置

### 任务 1: session-digest-weekly

**触发条件**: 每周一 09:00  
**输入文件**:
- `HANDOFF.md`
- `ERROR_PATTERNS.md` (用于关联)

**输出文件**:
- `SESSION_DIGEST.md`

**核心逻辑**:
```python
def analyze_weekly_sessions():
    # 1. 读取本周会话记录
    handoff_content = read_file("HANDOFF.md")
    
    # 2. 提取问题
    issues = extract_issues(handoff_content)
    
    # 3. 分类统计
    categories = categorize_issues(issues)
    
    # 4. 识别高频问题
    high_freq = filter_by_frequency(issues, threshold=2)
    
    # 5. 关联已有知识库
    for issue in high_freq:
        match = find_matching_error_pattern(issue)
        if match:
            issue['related_err'] = match
        else:
            issue['suggested_new'] = True
    
    # 6. 生成待办清单
    todo_list = generate_todo(issues)
    
    # 7. 更新文档
    update_session_digest(categories, high_freq, todo_list)
```

### 任务 2: knowledge-review-monthly

**触发条件**: 每月 1 日 10:00  
**输入文件**:
- `SESSION_DIGEST.md` (历史归档 + 待办清单)

**输出文件**:
- `ERROR_PATTERNS.md`
- `MEMORY.md`
- `SESSION_DIGEST.md` (月度总结)

**核心逻辑**:
```python
def monthly_knowledge_review():
    # 1. 读取本月待办清单
    todos = extract_todos("SESSION_DIGEST.md")
    
    # 2. 汇总建议
    suggestions = []
    for todo in todos:
        if todo['type'] == 'error_pattern':
            suggestions.append({
                'target': 'ERROR_PATTERNS.md',
                'content': generate_error_entry(todo)
            })
        elif todo['type'] == 'architecture':
            suggestions.append({
                'target': 'MEMORY.md',
                'content': generate_decision_entry(todo)
            })
    
    # 3. 生成月度报告
    report = generate_monthly_report(todos, suggestions)
    
    # 4. 更新 SESSION_DIGEST
    add_monthly_summary(report)
    clear_todo_list()
```

## 用户操作手册

### 日常开发流程

```
1. 开始工作
   └─► 查看 HANDOFF.md 了解当前阻碍

2. 遇到问题
   └─► 搜索 ERROR_PATTERNS.md
       ├─► 找到？→ 按解决方案执行
       └─► 未找到？→ 继续解决

3. 解决问题
   └─► 记录到 HANDOFF.md (供下周整理)

4. 周一早上
   └─► 查看 SESSION_DIGEST.md
       ├─► 了解本周趋势
       └─► 查看待办清单

5. 月底审核
   └─► 确认待办清单中的建议
       ├─► 有价值的 → 更新到正式知识库
       └─► 无价值的 → 标记忽略
```

### 手动触发整理

如需立即整理，可以：

1. **执行自动化任务**:
   ```
   WorkBuddy → Automations → session-digest-weekly → Run Now
   ```

2. **命令触发**:
   ```
   "请立即执行 session-digest-weekly 任务"
   ```

3. **直接操作**:
   ```
   "请基于本周 HANDOFF.md 内容，更新 SESSION_DIGEST.md"
   ```

## 效果度量

### 关键指标

| 指标 | 计算方式 | 目标 |
|------|----------|------|
| **知识沉淀率** | 知识库条目数 / 总会话问题数 | > 60% |
| **重复问题率** | 重复问题数 / 总问题数 | < 30% |
| **问题解决时间** | 从发现到解决的平均时间 | 持续下降 |
| **文档覆盖率** | 有知识库覆盖的问题 / 总问题 | > 70% |
