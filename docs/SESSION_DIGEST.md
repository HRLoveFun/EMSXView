# Session Digest & Knowledge Extraction

> 会话内容的周期性整理、问题聚类与知识沉淀。
> 目标：从碎片化的会话记录中提取结构化知识，保持知识库的时效性和完整性。

---

## 工具定位

### 这是什么？

这是一个**自动化知识管理工具**，通过定期分析项目内的会话历史（`HANDOFF.md`、聊天记录、日志等），提取有价值的信息并更新到知识库中。

### 与现有文档的关系

```
┌─────────────────────────────────────────────────────────────┐
│                    知识库金字塔                              │
├─────────────────────────────────────────────────────────────┤
│  L1 源头层  │  HANDOFF.md（原始会话记录）                    │
│             │  聊天记录 / 日志文件 / 代码注释                  │
├─────────────────────────────────────────────────────────────┤
│  L2 提炼层  │  SESSION_DIGEST.md ← **本工具**               │
│             │  定期整理、聚类、趋势分析                        │
├─────────────────────────────────────────────────────────────┤
│  L3 知识层  │  ERROR_PATTERNS.md（错误模式库）              │
│             │  MEMORY.md（架构决策）                          │
├─────────────────────────────────────────────────────────────┤
│  L4 入口层  │  CLAUDE.md（项目总入口）                        │
└─────────────────────────────────────────────────────────────┘
```

**工作流程**：
1. 原始会话记录 → 2. 定期整理摘要 → 3. 升华为结构化知识 → 4. 通过入口文档访问

## 自动化机制

### 定期整理任务

**任务名称**: `session-digest-weekly`  
**执行频率**: 每周一 09:00  
**工作目录**: `c:/Users/hrchen/Documents/EMSX`

**执行内容**:
```
1. 读取本周新增的会话记录（HANDOFF.md、聊天记录等）
2. 提取问题类型、解决方案、决策点
3. 分类统计：错误/功能/优化/配置
4. 识别值得升级到 ERROR_PATTERNS.md 的错误
5. 更新本文档的 "本期摘要" 和 "历史归档"
6. 生成 "待办更新" 清单（供人工审核）
```

### 二次更新机制

为了**平衡时效性和全面性**，采用**双轨制更新**策略：

#### 轨道 A：自动摘要（每周执行）
- **时效性**：高（每周更新）
- **全面性**：中（基于关键词和模式匹配）
- **人工介入**：低（仅查看）
- **产出**：`SESSION_DIGEST.md` 的 "本期摘要"

#### 轨道 B：人工审核（每月执行）
- **时效性**：中（每月更新）
- **全面性**：高（人工判断价值）
- **人工介入**：高（需确认）
- **产出**：`ERROR_PATTERNS.md` 和 `MEMORY.md` 的正式更新

```
每周自动化流程:
┌─────────────┐    ┌─────────────┐    ┌─────────────────┐
│ 收集会话内容 │ →  │ 自动分析聚类 │ →  │ 更新SESSION_DIGEST│
└─────────────┘    └─────────────┘    └─────────────────┘
                                               ↓
每月人工审核流程:                              ↓
┌─────────────┐    ┌─────────────┐    ┌─────────────────┐
│ 审核待办清单 │ →  │ 确认有价值项 │ →  │ 更新正式知识库   │
│ (来自Digest) │    │             │    │ (ERROR_PATTERNS) │
└─────────────┘    └─────────────┘    └─────────────────┘
```

## 自动化任务配置

### 任务 1: 每周会话摘要

```toml
name = "session-digest-weekly"
prompt = """
请分析本周项目内的会话内容（HANDOFF.md、聊天记录、日志等），完成以下任务：

1. **问题分类统计**
   - 统计各类问题数量（API错误/配置/功能开发/优化）
   - 对比上周趋势

2. **提取高频问题**
   - 识别重复出现 ≥2 次的问题
   - 关联已有的 ERROR_PATTERNS.md 条目
   - 标记新的潜在错误模式

3. **汇总解决方案**
   - 记录本周验证通过的新方案
   - 标注验证状态和是否值得入知识库

4. **生成待办清单**
   - 列出建议加入 ERROR_PATTERNS.md 的条目
   - 列出建议加入 MEMORY.md 的决策
   - 标注优先级

5. **更新 SESSION_DIGEST.md**
   - 更新"本期摘要"章节
   - 保留上一期内容到"历史归档"

输出格式：直接修改 SESSION_DIGEST.md 文件
"""
rrule = "FREQ=WEEKLY;BYDAY=MO;BYHOUR=9;BYMINUTE=0"
cwds = ["c:/Users/hrchen/Documents/EMSX"]
status = "ACTIVE"
```

### 任务 2: 每月知识库审核

```toml
name = "knowledge-review-monthly"
prompt = """
请基于本月的 SESSION_DIGEST.md 历史记录，完成知识库的定期维护：

1. **审核待办清单**
   - 检查 SESSION_DIGEST.md 中"待办更新清单"的内容
   - 评估每个建议项的价值

2. **更新 ERROR_PATTERNS.md**
   - 将高价值错误模式正式加入知识库
   - 更新现有条目的出现次数和最后日期
   - 合并相似条目

3. **更新 MEMORY.md**
   - 将重要的架构决策加入 MEMORY.md
   - 更新"已知限制"章节

4. **清理过期内容**
   - 删除已解决的临时阻碍
   - 标记已过时的解决方案

5. **生成月度报告**
   - 汇总本月知识库更新情况
   - 统计知识沉淀率（会话问题 → 知识库条目的转化率）

输出格式：
- 直接修改 ERROR_PATTERNS.md 和 MEMORY.md
- 在 SESSION_DIGEST.md 添加月度总结
"""
rrule = "FREQ=MONTHLY;BYMONTHDAY=1;BYHOUR=10;BYMINUTE=0"
cwds = ["c:/Users/hrchen/Documents/EMSX"]
status = "ACTIVE"
```

## 与 AI 助手的协作流程

### 用户视角

1. **每周一早上**：收到自动化生成的会话摘要通知
2. **快速浏览**：查看"高频问题"和"待办清单"
3. **采取行动**：对标记的条目决定是否加入正式知识库

### AI 助手视角

1. **执行定期任务**：自动分析、聚类、生成摘要
2. **提醒更新**：在会话中提示"这个问题似乎与 [ERR-XXX] 相关，是否更新？"
3. **协助审核**：在月度审核时提供建议

## 使用说明

### 查看当前周期摘要

打开本文档的 "本期摘要" 章节，了解本周：
- 遇到的主要问题类型
- 可用的解决方案
- 待人工确认的知识沉淀项

### 执行月度审核

每月初检查 "待办更新清单"，确认是否：
- 将新错误模式加入 `ERROR_PATTERNS.md`
- 将架构决策加入 `MEMORY.md`
- 更新现有条目的统计信息

### 手动触发整理

如需立即整理会话内容，可在 WorkBuddy 中执行：
> "请立即执行 session-digest-weekly 任务"
