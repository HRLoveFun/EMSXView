## 3. 定时调度入口
================================================================================

### CostView 每日更新调度
- **调度器**: `CostView/scripts/daily_update.py` — 使用 `schedule` 库，默认 18:00
- **Windows Task Scheduler**: `CostView/scripts/install_scheduler.py` — 注册 Windows 计划任务
  - 命令: `python daily_update.py --once`
  - 时间: 默认 09:00 (可配置 `--time`)
  - 管理: `--install` / `--uninstall` / `--status`

### CostView 主管线调度模式
- `python -m src --schedule` — 进入调度循环
- `python -m src --schedule-time 08:30` — 自定义时间
- `python -m src --schedule-once` — 单次运行后退出

### 日志清理调度
- `scripts/cleanup-logs.ps1` — 建议注册为 Windows 计划任务 (每日 3am)

## 6. 调用链总图
================================================================================

```
用户 ──双击──▶ start-services.bat
                │
                ├─▶ python ExecutionView/backend/api/start_server.py
                │       └─▶ uvicorn main:app (FastAPI, :3000)
                │
                └─▶ npm run dev (ExecutionView/frontend/, :5173)

用户 ──双击──▶ 重启服务.bat
                └─▶ scripts/service-manager.ps1 restart
                        ├─▶ stop (kill processes on :3000, :5173)
                        └─▶ start (同上)

定时 ──Windows Task Scheduler──▶ python daily_update.py --once
                                        └─▶ CostView 主管线 (fetch + process + aggregate)

开发 ──CLI──▶ python -m src [options]
                └─▶ CostView Fill Data Pipeline (多子命令)

AI ──stdio──▶ scripts/mcp/knowledge-server.py
                └─▶ MCP 知识库查询

运维 ──bash──▶ scripts/deploy/deploy.sh start
                └─▶ docker compose up (Nginx:80 → Backend:3000)
```
